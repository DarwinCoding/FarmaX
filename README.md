# FARMAX

Sistema de Gestion Farmaceutica Clinica

FarmaX es un sistema web para administracion farmaceutica clinica con inventario, ordenes, permisos y auditoria.

## Caracteristicas Principales

- Dashboard
- Inventario
- Ordenes
- Ordenes Especiales
- Reportes
- Usuarios
- Roles
- Permisos avanzados
- Auditoria
- Configuracion
- Backup
- Alertas
- Areas dinamicas
- Presentaciones dinamicas

## Tecnologias

- Node.js
- Express
- SQLite
- better-sqlite3
- express-session
- ExcelJS
- PM2
- Nginx

## Instalacion Rapida

```bash
npm install
npm start
```

Servidor local:

```text
http://localhost:3000
```

Usuario inicial:

```text
admin
```
